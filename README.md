# PokéGuía

Guía personal de los juegos de Pokémon: tipos por generación, dónde encontrar cada Pokémon con mapas reales, gimnasios y rivales, objetos con su ubicación, Mi equipo, Nuzlocke, shiny y herramientas (daño, captura, crianza…).

Es una web estática: abre `index.html` desde un servidor (por ejemplo GitHub Pages o `abrir_pokeguia.bat` en Windows). Se puede instalar en el móvil como app.

Los datos se generan con los scripts de `herramientas/` a partir de PokeAPI, PKHeX, Serebii, PokémonDB, WikiDex y los desensamblados de pret. Proyecto de uso personal, sin fines comerciales. Pokémon y sus nombres e imágenes son © Nintendo, Creatures y GAME FREAK.
